# Judges Testing Guide

## Project

VibeCoding Business Studio

## Track

Education

## What To Evaluate

This project has two parts:

1. the educational method: AI-assisted coding plus business coaching and team
   project ownership;
2. the demo vehicle: TempleFall, a mobile-first game prototype.

The prototype is intentionally small. It demonstrates how a large student idea
can be reduced into a working vertical slice.

## Install

```bash
npm install
```

## Run Locally

```bash
npm run dev
```

Open the local Vite URL shown by the terminal.

## Build

```bash
npm run build
```

Expected result: production build completes successfully.

## Demo Flow

1. Open the app in a browser.
2. Use a mobile viewport if possible.
3. Press the start button.
4. Click or tap the floor to move.
5. Pick up loot.
6. Tap bots to shoot after picking up a weapon.
7. Watch the safe zone shrink.
8. Trigger temple objectives and collect relics.

## Important Notes

- The game is a prototype, not a finished commercial game.
- The stronger educational artifact is the repeatable method documented in the
  README and learning-method document.
- The project includes prior work and Build Week extensions. The submission text
  explains what changed during Build Week.
