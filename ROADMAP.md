# Roadmap

## Product Hypothesis

A structured AI-guided workflow can help learners build real projects faster
without surrendering scope, verification, reflection, or product judgment.

## Current MVP

- project brief;
- scope challenge;
- milestone generation;
- guided Codex prompt;
- learner reflection;
- Markdown evidence export;
- plain-English judging and learner-facing copy;
- local persistence;
- optional server-side OpenAI coach;
- local fallback.

## Next Validation Work

### Learner usability

- Test with at least five learners.
- Measure whether they can explain the scope decision.
- Observe whether they can define verification evidence without prompting.
- Identify where language feels too abstract.

### Mentor usefulness

- Ask mentors whether the report is sufficient for feedback.
- Learn which decisions require explicit supervision.
- Test whether the rubric supports conversation rather than automated judgment.

### AI quality

- Compare local and GPT-5.6 scope plans.
- Evaluate whether generated milestones fit the learner's time and experience.
- Test for excessive praise, unnecessary features, and hidden assumptions.
- Record failure cases and revise prompts.

## Later, Only After Validation

- mentor comments;
- project templates by age and context;
- optional repository evidence;
- reusable rubrics;
- controlled classroom storage;
- team roles and approvals;
- project portfolio export.

## Explicitly Not Planned Yet

- a complete LMS;
- automated grading;
- payments;
- public profiles for minors;
- a marketplace;
- autonomous publication;
- silent repository changes;
- complex multi-agent orchestration.

These would increase product complexity before the learning loop is proven.
